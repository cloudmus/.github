## About

CloudMus is an open-source, multi-source music player with a front/backend architecture. It brings your streaming libraries and local files together, so you do not have to switch between apps.

- **Many sources:** Yandex Music, YouTube Music, local folders
- **Cross-platform:** Windows installer and Linux AppImage
- **Open source:** MIT licensed
- **Multilingual site:** English, Russian, German, French, Spanish, Italian
